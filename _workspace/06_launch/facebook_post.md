## 본문 (제품 중심)

Claude Code를 쓰다 보면 어느 순간 사용량 경고가 뜹니다. 그런데 **뭘 하다가 그렇게 됐는지는 아무도 안 알려줍니다.**

그게 궁금해서 도구를 하나 만들었습니다. tokenhabit이라고, 내 Claude Code 로그를 읽어서 토큰이 어디서 새는지 알려주는 CLI입니다.

```
uvx tokenhabit --lang ko
```

설치할 것도 없고, LLM을 부르지도 않습니다. `~/.claude`에 이미 쌓여 있는 세션 기록을 그냥 읽습니다. 전부 로컬에서 돌아가고 어디로도 전송하지 않습니다.

돌리면 이런 게 나옵니다.

**토큰 낭비 점수 D — 약 25% 낭비**
- 컨텍스트 과적재 · 270,006 토큰 → 50K 넘기 전에 `/compact`
- 대형 툴 결과 적재 · 136,942 토큰 → 요청 전에 범위를 좁혀라
- 파일 리드 재탕 ×27 → 재읽기 대신 컨텍스트 참조
- 최상위 모델 고정 주행 → 작업별로 `/model` 라우팅

제가 잡고 싶었던 건 "토큰을 많이 썼다"가 아니라 **"어떤 습관이 그걸 썼나"** 입니다. 그래서 습관마다 바로 칠 수 있는 커맨드를 같이 붙였습니다.

만들면서 알게 된 것 중 의외였던 게 몇 개 있습니다.

작업이 끝났는데 `/clear` 안 하고 다음 주제로 넘어가는 것. 이전 대화가 매 턴 다시 실려서 세션이 길수록 모든 턴이 비싸집니다. 빌드 로그를 통째로 붙여넣는 것도 마찬가지고요. 한 번 들어간 만 줄짜리 로그는 그 세션이 끝날 때까지 따라다닙니다.

반대로 흔히 낭비로 오해받는데 아닌 것도 있습니다. 세션이 길다거나, 서브에이전트를 많이 썼다거나, 상위 모델을 계속 쓴 것. 이건 그 자체로 낭비가 아니라서 세어서 보여주기만 하고 점수에는 넣지 않습니다.

지금 9개 카테고리에 31개 습관이 정리돼 있고, 그중 11개는 로그에서 자동으로 잡힙니다. 나머지는 로그에 흔적이 안 남는 것들이라 Claude Code 스킬 쪽에서 대화로 코칭합니다.

한 가지만 덧붙이면, 이 도구의 목적은 **적게 쓰기가 아닙니다.** 같은 결과를 더 싸게 얻어서 아낀 예산을 실제 작업에 쓰는 겁니다. 토큰 아끼느라 할 일을 못 끝내는 건 낭비보다 비싼 실수니까요.

한 번 돌려보시고 점수 나오면 알려주세요. 어떤 습관이 1위로 나오는지 궁금합니다.

## 짧은 버전 (~350자)

Claude Code 사용량 경고는 뜨는데 뭘 하다 그렇게 됐는지는 안 알려주죠. 그게 궁금해서 만들었습니다.

`uvx tokenhabit --lang ko`

내 로그를 읽어서 토큰이 어디서 새는지 점수와 순위로 보여주고, 습관마다 바로 칠 커맨드를 붙여줍니다. 설치 불필요, LLM 호출 없음, 전부 로컬.

작업 끝나고 `/clear` 안 하기, 빌드 로그 통째로 붙여넣기 같은 것들이 잡힙니다. 31개 습관 중 11개는 자동 감지.

github.com/epoko77-ai/tokenhabit

## 메모

- **이 글은 도구 설명이다.** 릴리스 뒷이야기(인용 검증·버그 수정 경위)는 여기 섞지 않는다. 필요하면 별도 글로.
- 본문의 점수·수치는 실제 출력과 동일(`python3 tests/make_demo_logs.py --lang ko`로 재현).
- 게시 시 링크는 첫 댓글로 빼는 편이 낫다 — 본문에 두면 링크 미리보기가 첨부 이미지와 겹친다.
